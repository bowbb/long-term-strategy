正式策略

基础配置
{% for asset, meta in asset_meta.items() %}{{ meta.label }} {{ base_weights[asset]|pct }}{{ ' / ' if not loop.last else '。' }}{% endfor %}
纳指
不参与均线择时，始终按基础配置参与每月再平衡；每月可按目标买入或卖出。
红利 / 黄金
每日判断：从低到高突破 MA250 上轨（+3%）恢复100%基础仓位；从高到低突破下轨（-3%）降至50%基础仓位；价格位于区间内时保持最近一次穿越后的50%或100%状态。
首次投入
没有历史状态时，区间内按100%基础仓位初始化，低于下轨则按50%基础仓位初始化。后续新增资金仍按当前目标比例投入，不会因为滞回区间而停留在现金。
执行
每月执行一次再平衡，使用执行日前最新已完成交易日的信号。日常可计算查看最新目标；计算不会自动确认交易完成。
释放资金
红利低波或黄金从满仓降至半仓时，释放其基础仓位的50%；释放资金各50%转入境内长期国债和人民币现金。国债和现金的基础配置继续保留。
缺失历史
红利低波或黄金有效历史不足250个交易日时，其基础权重全部转入境内长期国债。纳指不因历史不足而改变目标比例。
